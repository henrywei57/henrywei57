
I'm a student who learns by building. I like projects where software meets the physical world: robots, physics simulations, and baseball.

## Featured projects

**[Full Count](https://github.com/henrywei57/full-count)**
A broadcast-style 3D baseball game that runs in the browser. Zone hitting, meter pitching, real ball-flight physics, user-controlled fielding and baserunning, and online 1v1 and squad play. [Play it](https://henrywei57.github.io/full-count/)
`JavaScript` `Three.js` `Firebase`

**[HR Meter](https://github.com/henrywei57/mlb-hr-meter)**
A phone-first web app for the MLB game you're watching. Live win probability, home run chance, and a 3D view of the at-bat, installable as a PWA. [Live site](https://henrywei57.github.io/mlb-hr-meter/)
`JavaScript` `PWA`

**[Pitching Machine Simulation](https://github.com/henrywei57/pitching-machine-sim)**
A PyBullet simulation of a two-wheel pitching machine, from wheel spin-up to ball flight under gravity, drag and Magnus force.
`Python` `PyBullet`

**[Plant AIoT Dashboard](https://github.com/henrywei57/soil-sensor-dashboard)**
A live dashboard for soil sensor data (moisture, temperature, EC, pH, NPK) synced from a Google Sheet.
`JavaScript` `Chart.js`

**[ipynb to PDF](https://github.com/henrywei57/ipynb-to-pdf)**
Converts Jupyter notebooks to PDF entirely in the browser. No upload, no server.
`JavaScript`
